# Papers (with code where possible)
| Paper    | Repository | Notes |
| -------- | ------- | ------- |
| [A Comprehensive Survey on Knowledge Distillation](https://arxiv.org/abs/2503.12067) (Mansourian, 2025) | [Official repo](https://github.com/IPL-sharif/KD_Survey/tree/main) | This paper is very comprehensive but usefully shows a variety of different techniques, algorithms and applications|
| [Born Again Neural Networks](https://arxiv.org/abs/1805.04770) (Furlanello, 2018) | [Unofficial implementation](https://github.com/nocotan/born_again_neuralnet?utm_source=catalyzex.com)  | This looks at students that are the same size as their teachers, they tend to outperform the teachers|
| [Knowledge Distillation and Student-Teacher Learning for Visual Intelligence](https://ieeexplore.ieee.org/document/9340578) (Wang, 2022)| | A survey on KD with a particular focus on applications in Computer Vision |
| [Distilling the Knowledge in a Neural Network](https://arxiv.org/abs/1503.02531) (Hinton, 2015) | [Unofficial implementation](https://github.com/a7b23/Distilling-the-knowledge-in-neural-network)||
